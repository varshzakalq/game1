# Project Rewind

Project Rewind is a short 3D time-manipulation game created during a 48-hour game jam. The player can reverse time to escape danger, but doing so ages the protagonist and permanently reduces their ability to act. Each rewind comes with a cost: once youth is lost, it cannot be recovered.

The game focuses on tension, survival, and decision-making under pressure. Players must manage timing, movement, and risk as enemies use temporal attacks to accelerate aging and punish reckless rewinds.

## Engine and tech stack

- Engine: Godot Engine 4.6
- Rendering: Forward+ rendering pipeline
- Language: GDScript
- Genre: 3D action / time-manipulation game
- Project format: Godot project using a custom 3D scene setup and script-driven gameplay systems

The project is built in Godot 4 with GDScript, using the engine's built-in 3D features, input system, scene architecture, and scripting workflow. The current project configuration includes Godot's Forward+ renderer and standard 3D physics and input setup.

## Core gameplay features

- Time rewind mechanic: Press R to rewind time and undo recent motion or events.
- Perma-aging system: Each rewind causes the player to age forward, reducing speed and effectiveness over time.
- Enemy temporal attacks: Enemies fire time-based projectiles that rapidly age the player.
- High-risk timing: Age cannot be reversed, creating an ongoing strategic tradeoff between survival and momentum.
- Configurable controls: Controls can be adjusted in the in-game settings menu.
- 3D presentation: The project uses a full 3D gameplay space with movement, interaction, and combat-styled pressure.
- Jam-built assets: All 3D models were created during the 48-hour game jam window.

## Gameplay loop

1. Explore the 3D environment and avoid enemy temporal attacks.
2. Use rewind strategically to reposition, escape danger, or recover from mistakes.
3. Manage the aging penalty, since each rewind permanently reduces your youth and effectiveness.
4. Survive the encounter by balancing risk, timing, and movement.

## Controls

- Rewind: R (default)
- Move Forward: W
- Move Backward: S
- Move Left: A
- Move Right: D
- Jump: Space
- Sprint: Shift (if enabled in project input settings)
- Pause: Esc or configured pause action

Controls can be remapped in the Settings menu.

## How to play locally

1. Install Godot Engine 4.6 or the version used by the project.
2. Open this repository folder as a Godot project.
3. Press Play in the Godot editor.
4. To build a standalone version, install export templates and use the Godot export menu.
