# Project Rewind

Project Rewind is a short 3D game made for a game jam where you can rewind time at the cost of your own lifespan. Rewinding moves the world backward while aging your character forward — once youth is lost it cannot be regained.

- Rewind mechanic: press R to rewind time. Each rewind increases your character's age; aging reduces movement speed and effectiveness.
- Controls are configurable from the in-game settings.

All 3D models were created during the 48-hour game jam window!

## How to play

1. Run the game (see Build & Run below).
2. Use movement controls to navigate the level and avoid temporal projectiles that accelerate aging.
3. Press R to rewind time when necessary — but be careful, age is permanent.

## Controls
- Rewind: `R` (default)
- Movement: `W`/`A`/`S`/`D` (default)
- Look: Mouse (default)
- Jump: `Space` (default)

Controls are configurable in Settings -> Controls.

> Note: The project uses GDScript (Godot). If any control mapping differs for your platform, check the in-game settings.

## Build & Run (local)
1. Install Godot Engine (recommended: the version the project was built with; check `project.godot` or project settings for the exact version).
2. Open the repository folder as a Godot project.
3. Press Play in the Godot editor to run locally.
4. To create standalone builds, install Godot export templates and use Project -> Export.
